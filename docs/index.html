API 文档

GET / POST 均支持 · step 支持数字或"随机数" · 返回 JSON

01 基本信息
项目内容
接口地址(自动检测)
请求方式GET POST
内容类型application/x-www-form-urlencoded
返回格式application/json; charset=utf-8
频率限制同一 IP 每分钟最多 10 次
版本V3.0 · Zepp API
02 请求参数
参数必填说明
user是Zepp 账号(手机号或邮箱)
pwd是登录密码
step是目标步数(1~98800)或"随机数"(自动生成 18000~30000)
token是API 密钥, 固定值 666 (GET 请求必填, 网页表单 POST 可省略)
03 请求示例
# GET · 固定步数
$ curl "{API}?user=13888888888&pwd=yourpassword&step=28000&token=666"
# GET · 随机步数(18000~30000)
$ curl "{API}?user=you@example.com&pwd=yourpassword&step=随机数&token=666"
# POST · 网页表单提交(无需 token)
$ curl -X POST "{API}" -d "user=you@example.com&pwd=yourpassword&step=28000"
04 返回结果
字段说明
time提交时间(北京时间)
user脱敏后的账号
step实际提交的步数(随机模式返回生成值)
statussuccess 或 failed
message详细提示信息
# 成功响应
{
  "time": "2026-08-02 21:00:00",
  "user": "138****8888",
  "step": 28000,
  "status": "success",
  "message": "修改步数(28000)"
}
# 失败响应
{
  "time": "2026-08-02 21:00:05",
  "user": "138****8888",
  "step": 28000,
  "status": "failed",
  "message": "登录失败: 账号或密码错误!"
}
05 注意事项
1账号为 Zepp Life / 小米运动 账号, 不是小米账号
2需要先在 Zepp Life 中绑定微信 / 支付宝等第三方平台
3不建议使用 66666 / 88888 等特殊步数, 可能被判定异常
4登录信息缓存 7 天, 同一账号无需重复登录
5本工具仅供个人学习研究, 请勿商用
